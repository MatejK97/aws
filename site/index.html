// incidents.log

Things that broke, and what they taught me

Docker publishes ports around the firewall

Its iptables rules run before ufw, and Kubernetes NodePorts do the same. Admin services now bind only to the VPN address.

A security update that hid a container

An overnight libc update restarted containerd, and cAdvisor kept a stale socket. The alert fired, the logs pointed to the cause, and the mount was fixed for good.

Codifying a server is an audit

The first Ansible dry run found drift I hadn't noticed, including a Docker repository silently disabled by an OS upgrade.
